## 오늘 학습한 내용

### 1. Q-Learning의 한계와 DQN

- 기존 Q-Learning은 상태와 행동의 조합마다 Q값을 저장하는 Q-Table 방식이다.
- 현실 문제에서는 상태와 행동의 경우의 수가 너무 많아 모든 `Q(s, a)`를 계산하거나 저장하기 어렵다.
- DQN은 Q함수를 인공신경망으로 근사하여, 모든 상태를 테이블로 저장하지 않고 현재 상태를 입력받아 각 행동의 Q값을 예측한다.
- Q-Table에서 값을 직접 수정하던 방식이 신경망의 파라미터를 학습하는 방식으로 확장된 것이다.

---

### 2. Deep Q Learning의 구조

- Deep Q Learning은 현재 상태를 수학적으로 표현한 값을 신경망의 입력으로 사용한다.
- 출력값은 각 Action에 대한 Q값으로 해석된다.
- 학습 목표는 이상적인 Q함수 `Q*(S, A)`와 신경망이 예측한 Q값의 차이를 줄이는 것이다.
- 실습에서는 `CartPole-v1` 환경을 사용했다.
- 상태를 입력받아 왼쪽/오른쪽 행동의 Q값을 출력하는 신경망을 구성했다.
- 행동 선택에는 epsilon-greedy 방식을 사용하여, 초반에는 랜덤 행동으로 탐험하고 이후에는 Q값이 높은 행동을 선택하도록 했다.

```text
state -> neural network -> Q(left), Q(right) -> action 선택
```

---

### 3. DQN의 문제점과 보완 구조

- DQN은 신경망을 사용하기 때문에 학습이 불안정해질 수 있다.
- 첫 번째 문제는 관측값 간에 시간적 상관관계가 존재한다는 점이다.
- 딥러닝은 보통 데이터가 서로 독립적이고 같은 분포에서 나온다고 가정하지만, 강화학습에서는 연속된 상태들이 시간 순서대로 이어진다.
- 이를 완화하기 위해 Replay Buffer를 사용한다.
- Replay Buffer는 경험 데이터를 메모리에 저장한 뒤, 충분한 데이터가 쌓이면 랜덤하게 미니배치를 뽑아 학습한다.
- 이를 통해 데이터 순서를 섞고 시간적 상관관계를 약화시킬 수 있다.
- 두 번째 문제는 예측 Q값과 목표 Q값을 같은 신경망으로 계산하면 목표값이 계속 변한다는 점이다.
- 이를 완화하기 위해 Fixed Target 구조를 사용한다.
- Fixed Target은 예측용 신경망과 목표값 계산용 신경망을 분리하고, 일정 주기마다 예측 신경망의 값을 Target 신경망으로 복사하여 학습 안정성을 높인다.

---

### 4. DQN 실습에서 확인한 학습 흐름

- 상태, 행동, 보상, 다음 상태, 종료 여부를 Replay Memory에 저장했다.
- 메모리가 충분히 쌓이기 전까지는 학습하지 않고 경험만 저장했다.
- 이후 저장된 경험 중 일부를 랜덤하게 뽑아 현재 Q값과 목표 Q값의 차이를 계산했다.
- 현재 Q값은 모델이 출력한 여러 행동의 Q값 중 실제 선택했던 행동의 Q값을 `gather`로 가져와 계산했다.
- 목표 Q값은 `현재 보상 + 감가율 × 다음 상태의 최대 Q값` 형태로 계산했다.
- 에피소드가 종료된 경우에는 다음 상태의 미래 보상을 반영하지 않았다.
- 초반에는 reward가 낮았지만, 학습이 진행되면서 CartPole을 더 오래 유지하고 reward가 증가하는 것을 확인했다.

```text
state -> q_values -> action -> reward -> q_target -> loss -> update
```

### 5. DQN의 한계와 Policy Gradient

- DQN은 각 행동의 가치를 계산하는 방식이기 때문에 행동 공간이 연속적인 환경에서는 사용하기 어렵다.
- 모든 상태에서 하나의 행동을 선택하는 결정론적 정책이 항상 최적이라고 볼 수 없다.
- 이를 보완하기 위해 Q함수 대신 정책 함수 자체를 학습하는 Policy Gradient 방법이 등장한다.
- Policy Gradient는 어떤 행동을 선택할 확률을 직접 조정한다.
- 전체 결과가 좋았다면 그 행동을 선택할 확률을 높이고, 결과가 좋지 않았다면 낮추는 방식으로 정책을 학습한다.
- 목표는 정책을 따랐을 때 얻는 보상의 총합의 기댓값을 최대화하는 것이다.

---

### 6. Policy Gradient의 한계와 Actor-Critic

- Policy Gradient는 전체 궤적의 결과를 한 번에 평가하기 때문에 어느 행동이 실제로 좋은 결과에 영향을 주었는지 판단하기 어렵다.
- 보상의 분산이 크면 학습 효과가 불안정해질 수 있다.
- Actor-Critic은 이 문제를 완화하기 위해 정책을 담당하는 Actor와 행동의 가치를 평가하는 Critic을 분리한다.
- Actor는 현재 상태에서 어떤 행동을 할지 결정한다.
- Critic은 현재 상태와 행동의 가치를 평가한다.
- Actor는 Critic의 평가를 바탕으로 더 좋은 행동을 선택하도록 정책을 업데이트한다.
- Critic은 실제 보상과 예측 가치의 차이를 바탕으로 가치 함수를 업데이트한다.

### 7. ASR 강화학습 실습

- 한국어 ASR 실습에서는 Whisper 모델을 사용해 음성 인식 결과를 확인했다.
- SFT는 정답 transcript를 보고 그대로 따라 하도록 학습하는 모방학습 방식이다.
- 강화학습에서는 WER을 reward로 사용하여 음성 인식 결과가 정답에 가까워지도록 학습했다.
- 실습 결과 WER은 56.07%에서 47.10%로 감소했고, CER도 23.59%에서 18.77%로 감소했다.
- 보상 기반 학습이 실제 성능 개선으로 이어질 수 있음을 확인했다.
- 다만 고유명사나 외래어 인식은 여전히 어려움이 남아 있었다.

### 8. CarRacing 실습과 보상 설계

- CarRacing 환경에서는 에이전트가 제대로 주행하지 못하고 핸들만 돌리는 문제가 발생했다.
- 이를 통해 강화학습에서는 알고리즘뿐만 아니라 보상 설계가 매우 중요하다는 점을 알 수 있었다.
- 가속에는 보상을 주고, 불필요한 브레이크나 과도한 조향에는 패널티를 주는 방식으로 reward wrapper를 설계했다.
- 같은 환경과 같은 알고리즘을 사용하더라도 어떤 행동에 어떤 보상을 주는지에 따라 에이전트의 학습 방향이 달라질 수 있음을 확인했다.

## 핵심 개념 정리

| 개념 | 정리 |
|---|---|
| Q-Table | 상태와 행동 조합별 Q값을 저장하는 표 |
| DQN | Q함수를 신경망으로 근사하는 강화학습 알고리즘 |
| Replay Buffer | 경험을 저장한 뒤 랜덤 미니배치로 샘플링하는 구조 |
| Fixed Target | 목표 Q값 계산용 네트워크를 따로 두는 안정화 구조 |
| `gather` | 실제 선택한 행동의 Q값만 가져오는 연산 |
| Policy Gradient | 행동 선택 확률을 직접 학습하는 방법 |
| Actor-Critic | 정책을 담당하는 Actor와 가치를 평가하는 Critic을 분리한 구조 |
| WER | 단어 오류율 |
| CER | 문자 오류율 |
| Reward Wrapper | 환경의 보상 규칙을 재설계하는 구조 |

## 오늘의 회고

### 배운 점

- Q-Learning은 작은 상태 공간에서는 사용할 수 있지만, 현실 문제처럼 상태와 행동의 경우의 수가 많아지면 한계가 있다.
- DQN은 Q값을 테이블로 저장하는 대신 신경망으로 예측하여 더 복잡한 환경에 적용할 수 있다.
- Replay Buffer와 Fixed Target은 DQN의 학습을 안정화하기 위한 핵심 구조이다.
- Policy Gradient는 Q값을 계산하는 방식이 아니라 행동을 선택하는 정책 자체를 학습한다.
- Actor-Critic은 행동을 선택하는 Actor와 행동을 평가하는 Critic을 나누어 Policy Gradient의 한계를 보완한다.
- 강화학습은 모델만 학습시키는 것이 아니라 환경, 행동, 보상, 탐험 전략을 함께 설계해야 하는 분야이다.

### 어려운 점 / 개선할 점

- DQN에서 현재 Q값과 목표 Q값을 계산하는 흐름이 처음에는 헷갈렸다.
- Replay Buffer와 Fixed Target이 왜 필요한지는 이해했지만, 코드에서 실제로 어떻게 분리되고 업데이트되는지는 더 익숙해질 필요가 있다.
- Policy Gradient와 Actor-Critic은 개념적으로는 이해했지만, 수식과 코드로 연결하는 부분은 아직 어렵다.
- CarRacing 실습을 보면서 보상 설계가 생각보다 어렵고, 잘못 설계하면 에이전트가 의도하지 않은 행동을 학습할 수 있다는 점을 느꼈다.
