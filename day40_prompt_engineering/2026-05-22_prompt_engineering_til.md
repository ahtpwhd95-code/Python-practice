## 오늘 학습한 내용

### 1. LLM 기초 이론

- 언어 모델은 문장을 이해하고 생성하기 위해 발전해왔다.
- 초기 언어 모델은 단어의 등장 횟수와 확률을 기반으로 문장을 예측하는 방식이었다.
- 이후 신경망 기반 모델, 사전학습 언어 모델, 대규모 언어 모델로 발전했다.

```text
SLM -> NLM -> PLM -> LLM
```

- SLM은 통계적 언어 모델로, 단어의 등장 횟수를 바탕으로 확률을 계산한다.
- NLM은 신경망 기반 언어 모델로, 기초적인 문장 생성과 번역이 가능하지만 기울기 소실 문제가 있었다.
- PLM은 비지도학습을 통해 사전학습한 언어 모델로, NLP 분야 발전에 큰 영향을 주었다.
- LLM은 PLM 중 크기가 큰 언어 모델로, 대규모 데이터와 파라미터를 기반으로 높은 수준의 언어 이해와 생성 능력을 가진다.

---

### 2. GPT 계열 모델의 발전 과정

- GPT 모델은 Decoder 기반 언어 모델로 발전해왔다.
- GPT-1은 전이 학습으로 학습한 최초의 Decoder 기반 LLM이며, 비지도 사전학습 후 지도 미세조정을 수행했다.
- GPT-2는 지도 미세조정 없이 비지도 사전학습 중심으로 발전한 모델이다.
- GPT-3는 Meta-learning 기법을 적용해 다양한 형태의 문제를 하나의 모델이 처리하도록 유도했다.
- GPT-3.5는 지도학습과 인간 피드백 기반 강화학습을 활용해 대화형 AI 서비스 품질을 높였다.
- GPT-4는 이미지와 텍스트를 함께 처리할 수 있는 멀티모달 기능과 향상된 추론 성능을 제공한다.
- GPT-4o / GPT-4o mini는 멀티모달 처리 성능이 강화된 모델로 이해했다.
- OpenAI o1 / o3 / o4-mini는 복잡한 문제 해결과 단계적 사고 능력을 강화한 추론형 모델 계열로 이해했다.
- Deep Research는 Agentic Reasoning 개념과 연결되며, 다양한 출처에서 정보를 찾고 다음 행동을 추론하며 답변을 고도화하는 서비스로 이해했다.

### 3. 발전하는 언어 모델과 활용 방식

- PLM의 등장은 자연어처리 분야에 큰 혁신을 가져왔다.
- PLM과 LLM을 활용하는 대표적인 방식은 Fine-tuning과 Prompt Engineering이다.

```text
1. Fine-tuning
2. Prompt Engineering
```

- Fine-tuning은 특정 task에 특화된 데이터셋을 사용해 추가 학습을 진행하는 방식이다.
- Fine-tuning은 레이블이 존재하는 데이터셋을 활용하며, 모델의 가중치 일부 또는 전체를 업데이트할 수 있다.
- Prompt Engineering은 모델의 가중치를 직접 수정하지 않고, 자연어 명령인 prompt를 통해 원하는 작업을 수행하도록 유도하는 방식이다.

### 4. 생성형 AI 서비스의 발전 과정

- 생성형 AI 서비스는 텍스트, 이미지, 음성, 영상 등 다양한 형태의 콘텐츠를 생성하는 방향으로 발전하고 있다.
- 대표적인 상용 LLM 서비스로는 ChatGPT, Perplexity, Gemini, Claude, DeepSeek 등이 있다.
- ChatGPT는 OpenAI가 개발하고 출시한 생성형 AI 챗봇 서비스이며, LLM 서비스 대중화에 큰 영향을 주었다.
- 최근 ChatGPT는 음성 인식, 이미지 생성 등 멀티모달 기능도 강화되고 있다.

### 5. 프롬프트와 프롬프트 엔지니어링

- 프롬프트는 인공지능에게 전달하는 질문이나 지시를 의미한다.
- 사람이 생성형 AI 입력창에 입력하는 모든 질문과 명령이 프롬프트에 포함된다.
- 프롬프트 엔지니어링은 원하는 결과를 얻기 위해 좋은 프롬프트를 설계하는 것이다.
- 생성형 AI를 업무에 효과적으로 활용하기 위한 핵심 방법이며, AI와 협업하기 위한 의사소통 방식으로 볼 수 있다.

---

### 6. 프롬프트 활용 방법

- 프롬프트는 단순한 질문보다 구체적이고 명확하게 작성할수록 좋은 결과를 얻을 수 있다.
- 글의 톤을 지정하면 문장에 담긴 분위기와 감정이 달라진다.
- 작업을 한 번에 요청하기보다 단계별로 나누어 요청하면 답변 품질이 좋아질 수 있다.
- 특정 역할을 부여하면 모델이 해당 역할에 맞는 관점으로 답변한다.
- 표, 불릿포인트, 코드블록, 템플릿 등 원하는 답변 형식을 함께 제시하면 결과물을 더 쉽게 활용할 수 있다.

### 7. 이미지 및 영상 생성형 AI

- 이미지 생성 AI는 텍스트를 입력해 이미지를 생성하는 Text-to-Image 기술을 중심으로 빠르게 발전했다.
- 대표적인 이미지 생성 도구로는 DALL-E, Bing Image Creator, Adobe Firefly, Midjourney, Playground, Ideogram 등이 있다.
- 산업 현장에서 이미지 생성 AI를 사용하는 이유는 빠른 이미지 생성, 창의적인 스타일 구현, 외주 의존 감소를 통한 비용 절감이다.

```text
프롬프트 작성 -> 이미지 생성 -> 이미지 선택 및 수정
```

---

### 8. 이미지 생성 프롬프트 구성 요소

- 이미지 생성 프롬프트에는 주제어, 스타일, 디테일, 화풍이나 톤, 프레이밍, 카메라 뷰, 렌즈 효과 등을 구체적으로 작성할 수 있다.
- 프레이밍은 화면에 주제를 어떻게 배치할지 결정하는 요소이며, 이미지 구성을 좌우한다.
- Photography Prompt는 카메라 뷰, 렌즈, 조명, 구도 등을 조합해 이미지 생성 프롬프트를 작성하는 방식이다.
- Negative Prompt는 제외하고 싶은 요소를 명시하는 프롬프트이다.

## 핵심 개념 정리

| 개념 | 정리 |
|---|---|
| SLM | 단어 등장 횟수와 확률 기반의 통계적 언어 모델 |

## 오늘의 회고

### 배운 점

- LLM은 갑자기 등장한 기술이 아니라 SLM, NLM, PLM을 거쳐 발전해온 언어 모델이라는 것을 배웠다.
- GPT 계열 모델이 문장 생성에서 멀티모달, 추론, Agentic Reasoning 방향으로 발전하고 있다는 흐름을 이해했다.
- Fine-tuning과 Prompt Engineering은 PLM과 LLM을 활용하는 대표적인 방식이다.
- 프롬프트는 단순 질문이 아니라 AI에게 원하는 작업을 정확히 전달하기 위한 설계 과정이다.
- ChatGPT를 활용하면 웹페이지 제작, 코드 변환, 오류 수정, 데이터 분석 코드 작성까지 다양한 작업을 빠르게 실습할 수 있다.

### 어려운 점 / 개선할 점

- LLM 관련 용어가 많아 SLM, NLM, PLM, LLM의 차이를 구분하는 것이 처음에는 헷갈렸다.
- GPT 모델별 차이는 이름이 비슷해서 단순 암기보다 발전 흐름으로 이해해야 한다.
- 프롬프트 엔지니어링은 실제로 원하는 결과를 얻으려면 조건을 구체적으로 작성해야 한다.
- 이미지 생성 프롬프트에서는 주제, 스타일, 구도, 렌즈, 제외 요소 등을 함께 생각해야 해서 구성 요소가 많았다.
- ChatGPT가 생성한 코드는 항상 바로 정답이 아니므로 직접 실행하고 오류를 확인하는 과정이 필요하다.
