## 오늘 학습한 내용

### 1. 생성형 AI 기술 트렌드

- 최근 생성형 AI 흐름으로 멀티모달, 추론형 모델, AI Agent 개념을 학습했다.
- 멀티모달은 텍스트, 이미지, 비디오, 소리처럼 서로 다른 형태의 데이터를 함께 사용하는 모델이다.
- OCR은 이미지나 스캔 문서 같은 비정형 데이터를 컴퓨터가 읽을 수 있는 텍스트로 변환하는 기술이다.
- 객체 인식은 이미지나 영상에서 사람, 자동차, 동물 같은 사물을 찾아내는 기술이다.
- 이미지 세그멘테이션은 이미지의 각 픽셀이 어떤 사물에 속하는지 구분하는 기술이다.
- CAM, Grad-CAM은 모델이 이미지의 어느 부분을 근거로 판단했는지 시각화하는 방법이다.

---

### 2. 추론형 모델과 AI Agent

- 추론형 모델은 단순 질의응답이 아니라, LLM이 여러 단계의 추론을 거쳐 답변을 생성하는 모델이다.
- AI Agent는 특정 작업을 수행하기 위해 설계된 인공지능 시스템이다.
- Deep Research처럼 필요한 자료를 스스로 찾고 분석하여 보고서를 생성하는 형태도 AI Agent의 예시로 볼 수 있다.
- 조달청 공모전 프로젝트에 AI Agent 개념을 연결하면, 사용자의 목적에 맞춰 공공조달 데이터를 탐색하고 분석해주는 의사결정 보조 서비스로 확장할 수 있다.

---

### 3. GAN 기본 개념

- GAN은 2014년 Ian Goodfellow가 발표한 생성형 모델이다.
- GAN은 생성자(Generator)와 판별자(Discriminator) 두 모델로 구성된다.
- 생성자는 진짜 같은 가짜 데이터를 만들고, 판별자는 입력 데이터가 진짜인지 가짜인지 구분한다.
- 두 모델이 서로 경쟁하면서 생성자는 점점 더 자연스러운 데이터를 만들고, 판별자는 점점 더 정확하게 구분하도록 학습한다.

---

### 4. DCGAN

- DCGAN은 Vanilla GAN에 CNN 구조를 도입한 모델이다.
- 생성자는 전치 합성곱 층을 사용하여 이미지를 점점 크게 만드는 업샘플링을 수행한다.
- 판별자는 풀링 층 대신 스트라이드가 있는 합성곱 층을 사용하여 이미지를 줄이는 다운샘플링을 수행한다.
- DCGAN은 배치 정규화를 사용하여 기존 GAN의 기울기 소실, 기울기 폭발 문제를 완화한다.
- 생성자의 은닉층에는 `ReLU`, 출력층에는 `Tanh`를 사용한다.
- 판별자의 은닉층에는 `Leaky ReLU`, 출력층에는 `Sigmoid`를 사용한다.

---

### 5. CGAN

- CGAN은 GAN에 조건 정보를 추가한 모델이다.
- 생성자는 노이즈와 조건을 함께 입력받아 조건에 맞는 데이터를 생성한다.
- 판별자는 데이터가 진짜인지 가짜인지 판단하는 동시에, 주어진 조건을 만족하는지도 판단한다.
- 특정 숫자, 클래스, 스타일 등 원하는 조건을 넣어 더 구체적이고 제어된 데이터를 생성할 수 있다.

---

### 6. pix2pix

- pix2pix는 입력 이미지와 목표 이미지가 쌍으로 존재하는 데이터셋을 사용하여 이미지 변환을 수행하는 모델이다.
- 스케치를 실제 사진으로 바꾸거나, 흑백 이미지를 컬러 이미지로 변환하는 작업에 사용할 수 있다.
- pix2pix는 paired dataset, 즉 입력 이미지와 정답 이미지의 쌍이 필요하다.
- 지도학습 방식으로 이미지 변환을 학습한다.

---

### 7. CycleGAN

- CycleGAN은 입력 이미지와 목표 이미지가 쌍으로 존재하지 않아도 서로 다른 도메인 간 변환을 학습할 수 있는 모델이다.
- 말 이미지를 얼룩말 이미지로 바꾸거나, 여름 풍경을 겨울 풍경처럼 변환하는 작업에 활용할 수 있다.
- 핵심 개념은 Cycle Consistency이다.
- A 도메인의 이미지를 B 도메인으로 변환한 뒤 다시 A 도메인으로 복원했을 때, 원래 이미지와 비슷해야 한다는 원리를 사용한다.

---

### 8. 그 외 GAN 모델 흐름

- LSGAN은 최소제곱 손실 함수를 사용하여 학습 안정성을 개선한 모델이다.
- WGAN은 Wasserstein 거리를 사용하여 두 확률분포 사이의 차이를 더 안정적으로 측정한다.
- WGAN-GP는 가중치 클리핑 대신 Gradient Penalty를 도입하여 학습 안정성을 개선한다.
- BEGAN은 오토인코더 기반 판별자와 균형 손실 함수를 사용한다.
- ProGAN은 낮은 해상도부터 시작해 점진적으로 해상도를 높이며 학습한다.
- BigGAN은 대규모 데이터와 Self-Attention을 사용하여 고해상도 이미지를 생성한다.
- StyleGAN은 스타일 변수를 조절하여 이미지 생성 과정을 더 세밀하게 제어할 수 있다.

## 핵심 개념 비교

| 모델 | 핵심 아이디어 | 데이터 조건 |
|---|---|---|
| GAN | 생성자와 판별자의 경쟁 학습 | 일반 생성 데이터 |
| DCGAN | CNN 구조를 GAN에 적용 | 이미지 데이터 |
| CGAN | 조건 정보를 함께 입력 | 클래스, 라벨 등 조건 필요 |
| pix2pix | 입력 이미지를 목표 이미지로 변환 | paired dataset 필요 |
| CycleGAN | 짝이 없는 도메인 간 이미지 변환 | unpaired dataset 가능 |

## 오늘의 회고

### 배운 점

- 생성형 AI가 텍스트뿐만 아니라 이미지, 영상, 음성 등 다양한 데이터 형태와 연결된다는 점을 배웠다.
- GAN은 생성자와 판별자가 서로 경쟁하면서 학습한다는 구조가 핵심이다.
- DCGAN, CGAN, pix2pix, CycleGAN은 모두 GAN 기반이지만 목적과 데이터 조건이 다르다.
- pix2pix는 입력과 정답 이미지 쌍이 필요하고, CycleGAN은 짝이 없는 데이터도 사용할 수 있다는 차이가 중요하다.

### 어려운 점 / 개선할 점

- GAN 계열 모델 이름이 많아서 각 모델이 어떤 문제를 해결하기 위해 등장했는지 구분하는 것이 아직 헷갈렸다.
- 합성곱, 전치 합성곱, 스트라이드, 풀링 같은 CNN 관련 개념이 GAN 구조와 함께 나오니 복습이 필요하다.
- WGAN, WGAN-GP, BEGAN처럼 학습 안정성을 개선한 모델은 손실 함수와 확률분포 개념이 들어가서 한 번 더 정리해야 한다.
